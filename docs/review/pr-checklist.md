# PR准入条件清单

每个PR合并前必须满足：

- [ ] 关联真实Issue和具体Spec/AC（治理任务写明交付物）。
- [ ] 变更摘要解释问题及结果。
- [ ] AI使用说明包含工具、主要提示意图、生成范围与人工修改情况。
- [ ] 提供实际测试或手工验证证据，不把计划写成结果。
- [ ] 至少1名非作者人工评审。
- [ ] Agent/AI辅助评审对照Spec、AC、错误副作用和范围；不代替人工决定。
- [ ] 无文件白名单之外的业务修改，无未经许可的依赖。
- [ ] 适用测试通过；文档PR至少链接/追踪/依赖检查通过。
- [ ] 有歧义先改Spec；实现偏差修实现，不能降低验收标准。
- [ ] 分支名带真实Issue号；PR已在Projects的Review列关联。
- [ ] 风险、回滚与未解决限制明确。
