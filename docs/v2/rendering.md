# 地图材质与昼夜渲染

日期：2026-11-20。细化V2-AC-13、20，地图版本仍为3；地点、碰撞和业务规则不变。

## 画面调整

- 草地以较深的基础绿搭配低频明暗变化、细草纹；树冠使用不规则轮廓和叶簇，树干、落地阴影和受光方向保持一致。保留上轮减少后的树木数量。
- 道路为砂砾土路；工坊院落和装卸场采用石板，厨房与茶舍院落采用砖地，生产场地保留泥土地面。材质带有接缝、轻微磨损和明暗差，避免所有铺地都是同一种米黄色块。
- 河流采用浅岸到深槽的蓝绿色层次，增加浅水石块、岸边反射和沿岸石块。桥面加入木纹、拼缝与铆钉；动态水纹避开三座桥及停泊船区域。
- 建筑保留可观察室内的剖面样式，补充屋瓦、烟囱砖缝、木地板、墙边遮蔽和一致的右下投影。温室增加玻璃分格与反光；织机、茶桌、货箱和蜂蜜瓶补充材质及接触阴影。
- 晨昏、夜晚从服务端模拟时间连续插值；日间保持原材质色，黄昏偏暖，夜晚为冷色环境光。路灯与室内暖光随时间淡入，灯光坐标与实际灯杆共用配置，萤火集中在花田和营地。

## 修复与工程边界

旧实现将昼夜矩形的填充透明度设为0，再调整对象透明度，因此夜间遮罩一直不可见。这次填充保持不透明，只用对象透明度控制效果；实际像素回归验证了夜晚变暗和关闭效果后的恢复。

| 模块 | 职责 |
| --- | --- |
| game/art/materials.ts | 确定性石板、砖、木材、泥土纹理及接触／投影阴影 |
| game/art/building-shell.ts | 建筑剖面、地板、墙体、屋顶与烟囱 |
| game/art/lighting-props.ts | 路灯位置和静态灯杆绘制 |
| game/lighting.ts | 模拟时刻到环境色与灯光强度的连续曲线 |
| game/Atmosphere.ts | 动态水纹、昼夜覆盖、复用的灯光贴图和萤火 |

静态材质使用固定种子并在地图纹理生成时绘制，不在每帧重新生成。光晕贴图复用；环境更新频率上限24次/秒，不代表已测得整机稳定帧率。地图仍为3倍纹理采样，显示画布匹配设备像素比并上限2。页面创建时遵循系统减少动态效果偏好，冻结水纹运动并隐藏萤火。环境开关可以立即恢复原始材质色。

这是二维游戏的材质、投影与光晕绘制，不是三维物理光照或实时光线追踪。阴影主方向静态烘焙；窗内灯光和萤火是环境表现，不改变人物行为或能源资源。
