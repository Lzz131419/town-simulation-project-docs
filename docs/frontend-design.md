# 中文小镇桌面界面设计

## 目标与来源

2026-11-18用户要求参考斯坦福Smallville改造前端，并明确“中文，不是完全仿照”“目前只做好电脑端”。参考[Generative Agents / Smallville](https://github.com/joonspk-research/generative_agents)的俯视像素小镇、居民活动标记与观察方式；同时以用户提供的`PS_AI_Portfolio_2026-11-13_Offline.html`作为工作区导航、暖白面板、绿色状态和项目列表的实现参考。

本项目使用原创Canvas绘制的河流、桥梁、农田、室内家具、集市、广场、水井与像素居民，没有复制参考项目地图、人物贴图、标识或代码。雾河镇的名称、中文文案与公共决策玩法按本项目Spec设计。

## 信息与交互

- 桌面工作区由70px顶栏、160px左侧导航、主地图和300px右侧观察栏组成；1600px及以上视口将观察栏放宽为320px。地图占据主区的大部分空间，下方时间控制与最近事件保持紧凑。
- 主区为可缩放、平移的地图；右侧为居民档案/小镇事务；下方为时间控制和最近事件。地图专注按钮可收起顶栏、两侧面板和事件条，只保留地图与时间控制；Escape可退出。
- 地图居民、名单和下拉选择器同步选中，显示职业、精力、饥饿、缺水、余额、关系与最近10条行为。
- 姓名标记默认关闭，动作标记可开关；地图支持方向键平移、Escape复位，并提供按钮、居民名单和“扩大地图”作为键盘入口。
- 居民移动期间持续迈步、停留时恢复站姿；路段及循环边界连续。活动图标只在停留时按当前地点显示，社交虚线只连接停留在广场附近的真实互动伙伴。
- 导入人物、事件筛选使用弹窗；所有导入文本作为纯文本显示。
- 初次进入自动创建暂停世界；重置需要明确确认，推进/运行/短缺/投票/维修沿用应用层命令。

## 数据边界

地图的设施ID对应真实五类设施。居民活动取自当天该居民的事件；位置和过渡动画仅是展示布局，不写入世界快照，不表示已有逐格寻路或小时级行动。画面中的季节是场景装饰，未引入天气/季节规则。没有生成虚构的模型对话。

同日恢复不同快照时重新核对人物、姓名和活动，避免同人口同日期的旧画面残留；多人集中休息时分配不同展示位置。规则保持确定性，动画时钟仅存在于视图。

## 验证

桌面布局以70px顶栏、160px左侧导航和300px右侧观察栏为基准；地图区域随剩余空间伸展，底部事件区为单行64px且不裁切内容。此次不验收手机或窄屏。

44项Node测试含设施映射、不修改世界、按居民/当天筛选行为、31人休息布局、固定巡游路线和真实日程路径；浏览器验证导入、七日推进、短缺、维修、居民选择与事件筛选，结果见[验收记录](test/implementation-results.md)。

## 2026-11-19：工作区视觉优化

用户指定PS AI Portfolio网站作为前端风格参考，本轮提取绿色导航、暖白背景、深色标题、圆角白面板和浅阴影。采用中文左侧工作区导航，将小镇观察、居民档案、公共事务、事件簿集中组织；顶栏承载人物导入与存档操作。主区保持原创像素地图，资源摘要独立成浅色条，右侧观察面板使用分段选项与清晰状态层级。

界面使用暖白背景、深色正文和明亮绿色操作状态，配合圆角面板与浅阴影；使用系统中文字体，无远程字体或新增运行依赖。侧栏固定为160px，观察栏以300px为基准，地图根据剩余空间缩放，专注模式可收起两侧边栏。保留减少动态效果偏好。

导航实测覆盖公共事务入口与选中状态同步、居民搜索、返回完整小镇、事件弹窗；回归走通导入居民、七日推进、短缺、投票、维修及地图缩放。1440×900和1280×720无整页溢出。截图更新在原验收证据路径。

## 2026-11-19：地图呈现与文案收敛

用户复核后继续扩大地图在桌面工作区中的高度：标题、时间条和最近事件条压缩为操作所需信息，地图成为主视觉区域。地图背景使用2×画布采样并在显示前下采样，改善放大时的边缘清晰度；采样改进本身不等于新增细节，本轮另用0.5逻辑像素绘制叶片、窗框、地板缝和水纹。居民保持清晰像素绘制，姓名标签默认关闭，点击或悬停时仍显示对应居民，避免居民标签互相遮挡。草地、河水、土路和建筑改用明亮草绿、浅黄、蓝绿和灰白深边界的对比关系，借鉴Smallville的俯视观察感，但不追求完全还原，仍保留雾河镇自己的建筑、设施和中文内容。

地图、公共事务、人物导入和事件簿只保留状态、按钮、数值和短动作标签；初始状态不再弹出解释性提示。地点卡片说明压缩为“生产粮食”“取水与补给”等短标签。2×画布采样、放大地图、专注模式和默认姓名开关均属于视图层，不改变领域状态、快照字段或事件规则。
