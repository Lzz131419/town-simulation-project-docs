# 中文小镇桌面界面设计

## 目标与来源
2026-11-18用户要求参考斯坦福Smallville改造前端，并明确“中文，不是完全仿照”“目前只做好电脑端”。参考[Generative Agents / Smallville](https://github.com/joonspk-research/generative_agents)的俯视像素小镇、居民活动标记与观察方式。

本项目使用原创Canvas绘制的河流、桥梁、农田、室内家具、集市、广场、水井与像素居民，没有复制参考项目地图、人物贴图、标识或代码。雾河镇的名称、中文文案与公共决策玩法按本项目Spec设计。

## 信息与交互
- 主区为可缩放、平移的地图；右侧为居民档案/小镇事务；下方为时间控制和最近事件。
- 地图居民、名单和下拉选择器同步选中，显示职业、精力、饥饿、缺水、余额、关系与最近10条行为。
- 名称和动作标记可开关；地图支持方向键平移、Escape复位，并提供按钮和居民名单作为键盘入口。
- 导入人物、事件筛选使用弹窗；所有导入文本作为纯文本显示。
- 初次进入自动创建暂停世界；重置需要明确确认，推进/运行/短缺/投票/维修沿用应用层命令。

## 数据边界
地图的设施ID对应真实五类设施。居民活动取自当天该居民的事件；位置和过渡动画仅是展示布局，不写入世界快照，不表示已有逐格寻路或小时级行动。画面中的季节是场景装饰，未引入天气/季节规则。没有生成虚构的模型对话。

同日恢复不同快照时重新核对人物、姓名和活动，避免同人口同日期的旧画面残留；多人集中休息时分配不同展示位置。规则保持确定性，动画时钟仅存在于视图。

## 验证
1440×900与1280×720均无整页横向或纵向溢出，侧栏内容内部滚动；1200×800产品iframe用于性能验证。此次不验收手机或窄屏。

37项Node测试含设施映射、不修改世界、按居民/当天筛选行为和31人休息布局；浏览器验证导入、七日推进、短缺、维修、居民选择与事件筛选，结果见[验收记录](test/implementation-results.md)。
