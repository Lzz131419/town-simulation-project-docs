# 雾河镇单页技术探针

- 创建日期：2026-11-04
- 当前归类：技术探针
- 技术：HTML、CSS、原生 JavaScript、浏览器 `localStorage`
- 文件：`town-simulation-spike.html`

## 验证问题

在一个无需后端和构建步骤的页面中，能否呈现小镇总览、按日推进、居民详情、公共议题和事件时间线的基本交互方向？

## 已覆盖

- 30 名规则居民及基础职业分配。
- 精力、饥饿、余额、库存和关系等演示字段。
- 工作、消费、社交和粮食短缺的简单规则。
- 固定“维修老水井”议题与执行结果。
- 事件时间线、浏览器本地保存和 JSON 导出导入。
- 固定伪随机种子。

## 已知限制

- 设施只用于地图展示，没有形成正式设施状态对象。
- 投票结果和议题内容固定，没有居民立场与动态计票。
- 数字人物导入只有姓名输入，不是授权档案导入。
- 导入快照时没有恢复随机种子，不能保证完整复现。
- 导入字段进入 HTML 渲染前没有统一转义。
- 模拟逻辑、界面和数据全部位于单个 HTML 文件中，不适合六人并行开发。
- 所有数值和规则均为探针默认值，不是正式 Spec 参数。

## 结论

该探针验证了页面信息和交互方向可用于课堂讨论，但没有达到 MVP1 验收条件。正式实现必须等待第 7 周 Spec 和第 8 周 ADR，并在 `src/` 与 `tests/` 中建立可测试结构。
