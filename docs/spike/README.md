# 技术探针

本目录保存仅用于验证技术可行性、交互方向或技术风险的原型。探针不构成正式业务实现，也不作为 MVP1 验收证据。

每个探针应写清：

- 创建日期与负责人。
- 要验证的问题。
- 使用到的临时依赖及版本。
- 已实现的交互或数据范围。
- 已知限制和验证结论。
- 是否有进入正式实现的计划。
