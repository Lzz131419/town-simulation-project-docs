本轮阅读顺序：README → context → scope与五模块Spec → architecture/ADR → Plan → 交付检查。资料有冲突时按最新基线修订，不保留两份互相冲突的现行规则。

第9–11周Spec Owner和Reviewer轮换见Plan。模板、检查表可以预填结构，实际时间/PR号/评审结论必须等发生后填写。
