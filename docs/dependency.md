# 依赖与风险分析

## 1. 模块依赖图
```text
UI → M1应用编排 → M2 / M3 / M4 / M5 → Shared
```
箭头表示代码依赖；共享契约不依赖任何业务模块，M2–M5互不反向调用。业务操作顺序不是代码依赖。

## 2. 依赖规则
单向、无循环；UI只调用应用入口；不直接改world。模块间交接使用Result和事件草稿；公共契约变化走ADR。任务先后见 [mvp1-plan](../plans/mvp1-plan.md)，开发依赖与程序导入依赖分别记录。
