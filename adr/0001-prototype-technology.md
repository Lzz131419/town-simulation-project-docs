# ADR 0001 原型技术路线

- 状态：待团队确认
- 日期：2026-11-04

## 背景

第一阶段需要快速搭建可演示的 Web 原型，提供小镇配置、时间推进、状态查询和事件回放。项目构想提出 React/Vue 或现有静态主页、Python FastAPI 或同类服务、原型阶段 JSON/SQLite，以及服务端统一模型调用等备选建议，但没有记录已作出的最终选择。

## 候选方向

- 前端：React、Vue，或逐步改造现有静态主页。
- 后端：Python FastAPI 或同类轻量服务。
- 存储：先用 JSON/SQLite，验证后评估 PostgreSQL 或 MongoDB。
- 模型：服务端封装 OpenAI 兼容接口，模型提供方待定。

## 决策

暂不锁定具体技术。团队完成需求和已有代码盘点后，补充最终选型、原因、迁移成本与责任人，再将状态改为“已接受”。

## 后果

在决策确认前，需求文档只描述接口职责和数据能力，不依赖具体框架或数据库实现。任何进入实现阶段的技术选择应通过本 ADR 更新或新增 ADR 记录。
